# Bank Account Management System
A Java console-based application that allows users to perform basic banking operations such as
account creation, deposit, withdrawal, and balance enquiry using Core Java and OOP concepts.
## Features
- Create bank account
- Deposit money
- Withdraw money
- Check account balance
- Menu-driven console application
## Technologies Used
- Java
- Core Java
- Object-Oriented Programming (OOP)
## Future Enhancements
- Add PIN authentication
- Support multiple accounts
- Add file handling or database
- Create GUI using Swing or JavaFX
